# 민감도 Ki 후속 가설 검증 — 평가 전 고정 계획

시작 커밋 `5156715`. 앞선 400일은 가설 생성에만 사용하며 이번 확인 자료에서 설정을 선택하지 않는다. CMA 가중치·B 예측기·Kp 함수·누적 적분 상태·anti-windup·최종 승수 상한 1은 고정한다. NSGA-II는 종료 상태다.

## 가설과 사전 비교

1. **H1 (주 검증): 적응 고유의 추종 이득.** 기존 신뢰도 후보 G를 초기 6개 관측 대기 및 관측 부족 fallback=1 규칙이 같은 상수 대조군 C_matched와 비교한다. 상수는 새 보정 80일에서 G의 전체 평균 배율에 맞춘다. TE 차이가 주 지표다. 기존 항상 상수 C_all, 처음 6틱만 1인 C_warm, 같은 상수에 유효 관측 6개 기준을 적용한 C_rule을 함께 실행해 초기·후속 fallback 차이를 구별한다. 모든 규칙은 각 정책 자신의 과거 관측에 적용한다. 실제 fallback 발생 시점까지 강제로 같게 하지는 않는다.
2. **H2: 중심 보정과 EMA 초기값 불일치.** 기존 중심 보정 R의 초기 추정 이득 PRIOR 대신 `exp(center/power)`를 쓴 R_neutral을 비교한다. 중심·지수·목표 배율은 그대로다. 최초 적응 시 목표 배율 대비 로그 편차 및 첫 2시간 TE를 기전 지표로, 하루 TE·UR·V를 결과 지표로 기록한다. 최초 유효 비율로 초기화하는 R_first도 고정 보조 조건이다. 같은 두 변경을 G에도 적용한다. 유효 관측 전에는 모두 factor=1이다. neutral은 로그 적응 성분이 0이 되는 값이며 전체 factor가 1이라는 뜻은 아니다.
3. **H3: 학습 기울기의 EMA 지연.** 기존 학습 기울기 L의 alpha만 1로 바꾼 L_noema를 비교한다. 최근 12개 관측 특징은 유지하므로 모든 지연이 제거되는 것은 아니다. 새로운 자료에서 모델을 재학습하지 않는다.
4. **H4: 배율 제한의 영향.** L의 factor 범위만 [0.5,2]에서 [0.25,3]으로 바꾼 L_wide를 비교한다. Ki 자체 [0,6000], 최종 입찰 승수 [0,1] 및 anti-windup은 유지한다. 상·하한 기여를 개별적으로 분리하거나 무제한 효과를 주장하지 않는다.

정책 14개: CMA, G, C_all, C_warm, C_rule, C_matched, G_neutral, G_first, R, R_neutral, R_first, L, L_noema, L_wide. G/R/L과 C_all의 설정은 앞선 선택 파일 그대로다. 확인 결과에 따라 조건을 추가하지 않는다. 기울기의 기본 승수/실제 적용 승수 불일치는 이번 가설 검증 범위 밖에 남긴다. 해결하려면 별도의 작동점 학습·검증 설계가 필요하다.

## 자료·보정·판정

- 새 보정 80일: 450000–450079. G의 배율 평균만 사용하며 성능 기준으로 후보를 고르지 않는다. C_matched의 c를 `fallback_rate + (1-fallback_rate)*c = G_mean`에 맞추는 폐루프 반복을 최대 12회 한다. 허용 오차 1e-6, 실패하면 확인 평가를 시작하지 않는다.
- 새 확인 800일: 540000–540799. 구현 검사 610000–610004. 기존 확인 자료 및 최종 테스트 200000–200499와 분리한다. 코드를 동결한 뒤 보정하고, 배율을 동결한 뒤 확인을 시작한다.
- 800일은 이전 400일보다 평균 차이의 표본 오차를 약 1/sqrt(2)로 낮추기 위한 고정 실행 규모다. 작은 UR 개선에 충분한 검정력을 보장하는 수가 아니다. 사업상 허용 손실을 임의로 정하지 않고 엄격한 0 차이 기준을 유지한다. TE·UR 평균 비악화와 V 평균 감소는 기술적 통과 기준이며 통계적 비열등성과 구별한다. UR 단측 95% 상한도 보고한다.
- 날짜별 짝지은 bootstrap 20,000회(seed 20261121), 95% 구간을 모든 비교에 보고한다. H1 G−C_matched, H2 R_neutral−R, H3 L_noema−L, H4 L_wide−L의 하루 TE에는 4개 비교 Bonferroni 98.75% 구간도 사전 지정한다. 다른 지표·보조 조건은 탐색적 해석이다. H1의 추가 추종 이득 지지는 보정 구간 상한 <0일 때다. 효과 부재는 단순한 유의성 부재로 확정하지 않는다.
- 모든 정책을 원본 Python 시뮬레이터로 재실행해 가속 평가와 6개 지표 및 주요 진단값을 대조한다. 미래 경매 독립성·fallback·초기값·적분 상태·기준 정책 재현을 검사한다. 최종 테스트는 계속 차단한다.

결과는 배율 평균·평균 Ki·초기 행동·적분 상태의 차이를 함께 설명한다. 평균 배율 일치는 평균 Ki나 제어 경로 일치가 아니다. 이번 결과로 새 우승 모델을 고르거나 CMA 대체를 선언하지 않는다. 실제 시장으로 교정하지 않은 하루 단위 합성 first-price 환경의 가설 검증이다. 파일과 결과는 로컬에만 보존한다.
