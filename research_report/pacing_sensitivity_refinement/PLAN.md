# 민감도 기반 Ki 개선 실험 계획

시작점: `41b9c48`, NSGA-II 종료 상태 유지. 기존 결과와 최종 테스트 500일을 보존한다.

1. **Ki 증폭 편향 제거:** 초기 승수에서 정한 기준 이득을 그대로 사용하면 보정이 대부분 1보다 컸다. 별도 보정 자료에서 배율의 평균이 0.75·1·1.25가 되도록 중심을 맞춘다. p=0.25·0.5·1을 비교한다.
2. **불안정한 관측의 영향 축소:** 최근 지출/입력 비율의 잔차 변동이 크면 로그 보정량을 줄이는 신뢰도 가중치를 적용한다. 이 값은 직렬 상관을 반영한 통계적 신뢰구간이 아닌 고정된 휴리스틱이다.
3. **상태에 따른 기울기 학습:** B의 기울기는 상수다. 과거 관측과 기본 승수의 상호작용으로 국소 경매 차분 기울기를 예측하는 별도 회귀 모델을 학습한다. B의 기본 승수 선택과 CMA 가중치는 고정한다. 현재 경매 테이프는 개발 단계의 정답 생성에만 사용한다.
4. **동일 평균 배율의 대조군:** 각 적응 후보를 보정 자료에서 실제 실행한 평균 factor를 상수로 적용하는 대조군을 추가한다. 확인 자료에서 평균을 재보정하지 않는다. 따라서 확인 자료의 실제 평균은 달라질 수 있으며 함께 보고한다.

자료: 학습 240일(400000–400239), 새 중심·대조군 보정 80일(430000–430079), 새 선택 200일(440000–440199), 새 확인 400일(530000–530399). 이전 확인 자료를 재선택에 쓰지 않는다. 모든 설정과 모델 선택은 확인 평가 전에 동결한다.

주 방식은 중심 보정 비율 방식이다. 선택은 CMA 대비 TE·UR 평균 비악화와 V 감소를 모두 만족하는 후보 중 J 최소, 없으면 CMA 유지다. 각 방식의 J 최소 진단 후보도 미리 고정한다. 보정의 고유한 가치와 CMA 대체 여부는 별도로 판정하며, 배율 일치 상수와의 차이를 공개한다. 신뢰구간은 날짜 단위 paired bootstrap 20,000회, 다중 비교 보정 없는 기술적 구간이다. 평균 통과와 통계적 확실성을 구분한다.

구현 후 과거 행동의 미래 정보 독립성, 기준 정책 재현, 배율·예산 제한, 빠른 평가와 원본 시뮬레이터의 일치를 검사한다. 결과에 따라 새 실험 조건을 추가하지 않는다.
