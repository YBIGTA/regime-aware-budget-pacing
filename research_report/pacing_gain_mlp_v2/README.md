# 광고 예산 페이싱 · 상태별 PI 계수 신경망 재학습

기존 상태별 PI(B_state_PI, C_state_PI)의 계수 신경망을 더 잘 학습시키면 성능이 좋아지는지 확인했다.
구조는 그대로 두었다(입력 7 → tanh 4 → Kp, Ki). 바꾼 것은 학습 방법, 학습일 수, 입력 하나뿐이다.
최종 테스트 500일(200000~)은 사용하지 않았다.

| 항목 | 기존 | 이번 |
|---|---|---|
| 학습 방법 | 무작위 탐색 24회 | CMA-ES (후보 12개 × 60세대 = 720회) |
| 학습일 | 400000~400023 (24일) | 400000~400079 (80일) |
| 출발점 | 학습 24일에서 고른 고정 PI | 학습 80일에서 다시 고른 고정 PI (B: Kp 49.543, Ki 150 / C: Kp 49.543, Ki 75) |
| 후보 선택 | — | 별도 40일 (400080~400119) |
| 검증 | 100000~100199 (200일) | 같은 200일, 최종 선택 모델만 **1회** 평가 |

학습 기준은 두 가지를 모두 썼다.
- **합산**: 추종 오차 + 미소진율
- **벌점**: 합산 + 10 × max(0, 추종 오차 − 학습일 고정 PI의 추종 오차)

### 기존 상태별 PI와 같은 날짜끼리 비교 (부트스트랩 20,000회, 95% 구간)

추종 오차·미소진율·합산은 %p, 승수 변동은 원 단위다. 음수가 개선이다.

| 비교 | 추종 오차 | 미소진율 | 합산 손실 | 승수 변동 |
|---|---|---|---|---|
| B 합산 − B_state_PI | −0.00255 [−0.00389, −0.00120] | −0.01380 [−0.01836, −0.00952] | **−0.01635** [−0.02076, −0.01215] · 141일 개선 | **+0.01688** [+0.01493, +0.01881] · 178일 악화 |
| B 벌점 − B_state_PI | −0.00379 [−0.00507, −0.00251] | −0.00864 [−0.01288, −0.00457] | **−0.01243** [−0.01654, −0.00853] · 137일 개선 | **+0.01195** [+0.01096, +0.01293] · 189일 악화 |
| C 합산 − C_state_PI | +0.00039 [−0.00123, +0.00197] | −0.02268 [−0.02915, −0.01642] | **−0.02229** [−0.02916, −0.01566] · 131일 개선 | +0.00392 [+0.00029, +0.00747] |
| C 벌점 − C_state_PI | −0.00567 [−0.00710, −0.00430] | −0.01168 [−0.01744, −0.00607] | **−0.01734** [−0.02344, −0.01141] · 142일 개선 | −0.01136 [−0.01441, −0.00842] |

- 네 모델 모두 기존 상태별 PI보다 합산 손실이 낮다. 감소폭은 B 8.3%·6.3%, C 11.0%·8.6%이며, 구간은 모두 0을 포함하지 않는다.
- **C 벌점 모델**은 추종 오차, 미소진율, 합산 손실, 승수 변동이 모두 C_state_PI보다 낮다.
- **B 두 모델**은 추종 오차, 미소진율, 합산 손실은 개선됐지만 **승수 변동이 커졌다**(178·189일 악화). 고정 PI와 비교하면 B 벌점 모델의 승수 변동은 오히려 낮다(−0.00254 [−0.00439, −0.00077]).
- **C 합산 모델**은 개선이 미소진율에서만 나왔다. 추종 오차는 차이가 불분명하고 승수 변동은 약간 커졌다.
- 벌점 기준은 합산 기준보다 추종 오차와 승수 변동을 낮추고, 대신 미소진율을 조금 높였다. 이 경향은 B와 C에서 같다.
- 고정 PI와 비교하면 네 모델 모두 합산 손실이 0.029~0.034%p 낮다.

## 학습 설정별 비교 (후보 선택 40일, B)

기존 B_state_PI는 0.16052%, 학습일 고정 PI는 0.16969%다.

| 설정 | 시드 | 합산 기준 | 벌점 기준 |
|---|---|---:|---:|
| E1a: CMA-ES, 24일 | 1 | 0.16493% | 0.14804% |
| E1b: CMA-ES, 80일 | 1 / 2 | 0.14973% / 0.15238% | 0.15473% / 0.15083% |
| E2: E1b + 많이 밀림 입력 | 1 / 2 | **0.14843%** / 0.15154% | **0.14702%** / 0.15018% |

(각 실행에서 '학습 중 최고 후보'와 'CMA-ES 평균' 중 더 나은 값)

- 80일로 학습한 설정(E1b, E2)은 시드·기준과 무관하게 8개 모두 기존 B_state_PI보다 낮다.
- 24일 학습(E1a)은 기준에 따라 엇갈렸다. 합산 기준은 0.165%로 B_state_PI보다 나빴고, 벌점 기준은 0.148%로 좋았다. 학습일을 늘리면 결과가 안정되는 것으로 보이지만, 실행이 1회뿐이라 단정하지 않는다.
- '많이 밀림' 입력(E1b→E2)의 효과는 시드 간 차이(약 0.003%p)와 비슷하거나 작아서 분리하지 못했다.
- C도 같은 경향이다(`results_C/holdout.csv`). 최종 선택은 B, C 모두 두 기준에서 E2였다.

## 점검과 주의

- 새 코드에 기존 가중치를 넣으면 저장된 B_state_PI·C_state_PI 점수와 정확히 같다(3일, 차이 0). 8입력에서 추가 입력 가중치가 0이면 7입력과 같다.
- E1a 벌점 실행은 처음에 벌점 기준 추종 오차를 80일 값으로 잘못 계산했다. 24일 값으로 고쳐 다시 실행했다. 이전 결과는 `*_refbug*.bak`으로 남겼다. 재실행 뒤에도 최종 선택은 바뀌지 않았다(`picks_before_e1a_rerun.json`과 같음).
- B 결과는 C 지원을 추가하기 전의 코드로 실행했다. 추가 후에도 B 재현 점검이 같게 나오는 것을 확인했다.
- 학습 설정당 시드는 2개뿐이다. 시드 간 차이가 작지 않으므로 설정 간 비교는 참고로만 본다.
- 검증 200일은 최종 선택 모델 4개만 한 번 평가했다. 다만 이 200일은 이전 실험들에서 이미 여러 번 본 날짜다. 일반화 확인은 최종 테스트 500일에서 해야 한다.
