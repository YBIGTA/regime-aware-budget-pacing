## 실행 과정

1. 초기 파일럿: 계수 후보 40개, 검증 20일.
2. 확대 탐색: 전역 후보 512개, 주변 후보 256개. 기본 승수도 탐색.
3. 개발 평가 32·64·128·256일, 검증 200일, 개발 점검 200일.
4. Ki 상한 1,000에서 선택되어 다른 값을 고정하고 Ki 범위를 추가 점검.
5. Ki=3,000 선택. 더 큰 값에서 성능 악화를 확인.

B·C 공통 학습 데이터는 1,000일, 288,000구간으로 생성했다.
최종 테스트 500일은 예약했으나 아직 실행하지 않았다.
세부 설정과 실제 결과는 아래 원본 프로토콜·결과 파일을 기준으로 한다.

## ABC 비교 규칙

- 주 비교: 선택된 A의 PI 계수와 초기 승수를 공통 적용하고 예측 모듈 추가 효과 평가.
- 보조 비교: 모델별 최선 성능은 동일 환경·동일 종단간 탐색 예산으로 각각 튜닝.
- B·C의 입력 정보·학습 데이터·후보 승수·선택 방식 통일.
- 모든 모델에 동일한 외부 경매 흐름·행동 한도·PI 구현·예산 검사 적용.
- 이전 구간까지의 정보만 사용.
- 세 모델 설정을 동결한 뒤 같은 미사용 최종 테스트로 평가.

## 해석 범위

현재는 실제 데이터로 교정하지 않은 무작위 first-price 공학 검증 환경이다.
Yahoo 원본 재현 또는 AuctionNet fixed-price replay와 동일한 실험이 아니다.
유한 탐색과 Ki 범위 점검을 완료했으며 전역 최적성을 보장하지 않는다.
B·C의 학습 및 최종 비교 결과는 아직 포함하지 않는다.
