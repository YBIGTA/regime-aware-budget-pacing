BOA는 실제 결합 행동의 경로에서 평가했다. 기존 실험의 지표를 가중 평균한 값이 아니다.
가중치 갱신에는 완료된 경매 구간의 가상 재실행을 사용한다. 실제 광고 로그만으로 가능한 방식은 아니다.
이 갱신 손실에 BOA 공식을 적용한 탐색 실험이며, 제어 성능에 대한 BOA 이론 보장을 주장하지 않는다.
