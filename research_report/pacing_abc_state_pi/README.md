# 광고 예산 페이싱 · 고정 PI와 상태별 PI

동일한 경매 데이터로 검증한 200일 결과다. 합산 점수는 추종 오차와 미소진율의 합이다.

| 모델 | 추종 오차 ↓ | 미소진율 ↓ | 합산 점수 ↓ | 승수 변동 ↓ |
|---|---:|---:|---:|---:|
| A · 기존 고정 PI | 0.135915% | 0.088211% | 0.224126% | 0.085853 |
| B · 고정 PI | 0.139129% | 0.076141% | 0.215270% | 0.096369 |
| B · 상태별 PI | 0.141532% | 0.055894% | **0.197426%** | 0.081878 |
| C · 고정 PI | 0.139151% | 0.074232% | 0.213383% | 0.088812 |
| C · 상태별 PI | 0.138814% | 0.063211% | 0.202025% | 0.103108 |

B는 선형 회귀, C는 신경망으로 다음 5분 지출을 예측한다.
고정 계수와 상태별 계수 모델은 동일한 별도 24일에서 조정했다.
B의 고정 계수는 Kp=49.543385, Ki=300.000000다.
C의 고정 계수는 Kp=49.543385, Ki=0.000000다.
상태별 PI는 매 5분 Kp와 Ki를 계산한다. 최종 테스트 500일은 사용하지 않았다.

## 재실행

Python 3.11 이상에서 저장소 루트 기준으로 실행한다.

    bash research_report/pacing_abc_state_pi/replay.sh

재실행은 저장된 B·C 지출 예측기를 불러와 계수 탐색과 200일 검증을 다시 수행한다.
C 원본 코드는 실행 당시의 P 전용 진단도 포함한다.
B 공유용 코드는 C 결과 경로를 상대 경로로 바꿨으며 원본 해시는 체크포인트에 기록했다.
경매 해시 검증에는 원래 실행 환경과 동일한 수치 연산 결과가 필요하다.
