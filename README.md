# 광고 예산 페이싱: PI 기준 모델과 지출 예측

광고 경매에서 목표 누적 지출 곡선을 얼마나 정확하게 추종하는지 평가한다.
고정 PI를 기준으로 선형 회귀·신경망의 지출 예측을 추가하는 실험을 준비한다.

## 현재 상태

- A: 고정 PI 구현, 확대 탐색 및 Ki 범위 점검 완료.
- B: 선형 회귀 지출 예측 + PI, 구현·평가 예정.
- C: 신경망 지출 예측 + PI, 구현·평가 예정.
- 최종 테스트: 아직 실행하지 않음.
- 이전 레짐·클러스터링 시도는 연구 기록으로 보존.

## 비교 모델

| 모델 | 기본 입찰 강도 결정 | 공통 부분 |
|---|---|---|
| A | 튜닝한 고정값 | PI 보정·행동 한도·예산 검사 |
| B | 선형 회귀 지출 예측으로 후보 선택 | A와 동일 |
| C | 신경망 지출 예측으로 후보 선택 | A와 동일 |

## 공정한 비교

- 주 비교: 선택한 A의 PI 계수와 초기 승수를 공통 적용해 예측 모듈 추가 효과 평가.
- 보조 비교: 모델별 최선 성능은 동일 환경과 동일 탐색 예산으로 각각 튜닝.
- B·C의 입력·학습 데이터·후보 승수·선택 방식 통일.
- 같은 경매 흐름, 갱신 간격, 행동 한도, 예산 검사 사용.
- 이전 구간까지의 정보만 입력에 사용.
- 모든 모델 설정을 동결한 뒤 같은 미사용 최종 테스트로 평가.

## 결과 보존과 복원

학습 데이터·개별 실행 기록·로그를 포함한 전체 원본은 A 보고서의
분할 압축 파일에 보존했다. 해당 보고서 폴더의 restore_originals.py를
실행하면 새 임시 폴더에 복원하고 원본별 SHA-256을 확인한다.

## 해석 범위

현재 환경은 실제 데이터로 교정하지 않은 무작위 first-price 공학 검증 환경이다.
실제 시장을 대표하거나 전역 최적 PI를 확보했다는 주장은 하지 않는다.
기존 AuctionNet fixed-price replay와 같은 조건의 실험으로 취급하지 않는다.
